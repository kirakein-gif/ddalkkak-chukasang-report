# 딸깍 추카상 보고서 — 서버 없는 웹버전 v0.1

기존 `업무추진비 및 법인카드 추출_v18(배포).xlsb`의 VBA 동작을 브라우저형으로 옮긴 1차 구현입니다.

**추**진비 · **카**드 · **상**품권을 한 번에 처리하는 보고서 자동생성 도구입니다.

- 고양이 아이콘 2: `file_000000008e848206972ec970f432df61.png` — 보조 마스코트 자산으로 보관

## 현재 구현
- K-에듀파인 `예산거래처별 실적조회` Excel 파일 읽기
- 파일은 브라우저 내부에서만 처리(서버 업로드 없음)
- 업무추진비: `일반업무추진비` 추출 → 1차 분류 → 분류/집행대상자 직접 검토
- 법인카드: 카드결제 중 업무추진비 50만원 이상 / 기타 100만원 이상 자동 추출·분류
- 상품권: 세부내역의 `상품권` 추출, 권종/수량 확인 후 액면총액·할인율 계산
- 여러 달이 섞여 있으면 기준월 선택
- 3종 보고서 HTML 미리보기
- 개별 XLSX 및 전체 ZIP 다운로드

## 원본 파일 형식
K-에듀파인에서 내려받은 **예산거래처별실적(원인행위)** 파일을 기준으로 합니다.

상단에 보고서 제목/빈 행이 있어도 자동으로 헤더 행을 찾습니다. 현재 확인한 실제 파일의 핵심 열은 다음과 같습니다.
- 일자
- 제목
- 원인행위액
- 목
- 원가통계비목
- 수령인
- 지급방법

열 위치를 고정 숫자로만 읽지 않고 헤더명으로 찾아 처리합니다.

## 상품권 v18 대비 변경
기존 VBA는 `할인 후 결제금액 ÷ 권종`으로 수량을 역산하여, 할인 구매 시 실제 액면총액을 잘못 계산할 수 있습니다.
웹버전은 세부내역에서 `100매`, `100장` 같은 수량을 찾으면 자동확인하고, 찾지 못하면 `확인 필요`로 표시하여 사용자가 수량을 직접 확정합니다.

## 실행
정적 파일이므로 웹서버에서 `index.html`을 열면 됩니다. GitHub Pages에 그대로 배포할 수 있습니다.

엑셀 읽기/생성 라이브러리는 CDN에서 로드합니다. 첫 접속 시 인터넷 연결이 필요합니다.

## GitHub Pages
1. 저장소 루트에 `index.html`, `styles.css`, `app.js` 업로드
2. GitHub → Settings → Pages
3. Deploy from a branch → `main` / root 선택
4. 발급된 Pages 주소 접속
